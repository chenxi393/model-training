先解决一个分类问题

我们要判断：两个条件里，是否恰好满足一个？先看这个问题为什么不能只画一条直线解决，再看隐藏单元和 ReLU 各自帮了什么忙。

我们到底要预测什么？

一个很小的二分类问题

把 x1 和 x2 看成两个条件：1 表示满足，0 表示不满足。目标是判断“恰好一个条件满足”，也就是下面两种情况：

(1, 0) → 1只有第一个条件满足，是正类
而
(0, 0)、(1, 1) → 0一个都不满足，或两个都满足，是负类

为什么需要隐藏单元？

如果只有一个加权求和，x1、x2 对分数的影响会直接相加。这样“分别满足一个条件”时分数变大，“两个条件都满足”时分数也会更大，很难把最后一种情况判回 0。隐藏单元让模型先做中间判断，再组合答案。

h1：至少一个条件满足 h2：两个条件都满足 有 h1、没有 h2 → 恰好一个 → 预测 1 有 h1、也有 h2 → 两个都满足 → 预测 0

拖动输入时，可以对照下面的 h1、h2 数值观察这个过程。

x：输入 y：正确答案 模型：根据 x 算出预测 loss：预测和 y 的差距

这一页只是在观察“模型如何一步步计算预测”，还没有开始训练。

先看这三件事

不要背定义

1. 先把输入当成开关

x1、x2 只有 0 和 1。先数开了几个，再看 h1、h2 分别用不同门槛回答什么问题。

2. 什么是隐藏单元？

把它想成一个小计算器。它拿到所有输入，每个输入乘一个自己的权重，最后加上偏置：w1*x1 + w2*x2 + b。h1 和 h2 只是两台用途不同的计算器。

3. ReLU 是什么？

ReLU 不是另一个隐藏单元，而是一个简单的开关：ReLU(z) = max(0, z)。负数变 0，正数保留。h1、h2 的 before 和 after 会把这件事直接显示出来。

4. 这些数字不是凭空来的

-0.5 让 h1 在“至少一个”时变正，-1.5 让 h2 只有在“两个都满足”时变正。它们是两个不同的门槛。

5. 输出层做最后组合

这里的 2、-6、-0.5 只是为了让这四种输入得到正确分类而手工选的一组参数，不是固定答案。真实训练时，它们会由数据和 loss 学出来。

h1 = 1.0*x1 + 1.0*x2 - 0.5 h2 = 1.0*x1 + 1.0*x2 - 1.5 relu(h) = max(0, h) logit = 2.0*relu(h1) - 6.0*relu(h2) - 0.5

从玩具网络到 MNIST

计算没有变，规模变了
