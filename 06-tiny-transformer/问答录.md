# 06 问答录

这里记录学习 Tiny Transformer 时最容易混淆的问题。建议先自己说一遍，再看答案。

## 学习记录：Embedding 小数是不是模型对字符的评分？

你的回答是：“三个小数会改变，因为训练后得到的分数会变，不同维度的分数是模型对字符的理解。”

其中“训练会修改三个小数”抓住了可训练参数这个重点。需要继续区分特征表示和输出分数：

```text
字符 ID → 查表得到 Embedding 特征 → 网络计算 → 候选答案的 logits
```

Embedding 中的数供后续计算使用，各维通常没有固定的人类含义。输出层的每个 logit 才对应一个候选字符，但也还不是概率。最终 softmax 把这些 logits 变成候选字符概率。

训练时，最终 loss 的梯度传回 Embedding 表，优化器据此更新小数，ID 映射保持不变。可以运行 [真实预测练习](./prediction_learning_demo.py)，对照训练前后的 Embedding、正确答案 logit、概率和 loss。

## 学习记录：两个 softmax 有什么不同？

| 用在哪 | 输入 | 输出含义 |
| --- | --- | --- |
| Attention 内部 | 对各个可见位置的匹配分数 | 读取各位置的权重 |
| 模型输出端 | 对词表各个候选字符的 logits | 下一个字符的概率 |

两个地方都使用 softmax，但操作的对象不同。Attention 汇总得到的向量仍是特征；经过后续网络和输出层，才会得到候选字符 logits。

## 1. Transformer 到底在解决什么问题？

本章的 Transformer 只解决一个明确任务：

> 根据已经出现的字符，预测下一个字符的概率。

例如看到：

```text
模型训
```

它会给词表里的每个字符一个分数，“练”可能得分较高。生成程序选出一个字符追加到末尾，再让模型预测下一次。

## 2. 为什么 input 和 target 要错开一位？

因为每个位置的答案就是它右边的下一个字符：

```text
原文   = 模 型 学 习 。
input  = 模 型 学 习
target = 型 学 习 。
```

这样一段长度为 4 的输入可以同时得到 4 道训练题。模型不是把 input 原样复述出来，而是在每个位置预测接下来是什么。

## 3. 为什么训练时能一次预测所有位置？

因为正确的整段训练文本已经存在，我们可以同时构造每个位置的 target。causal mask 保证位置 1 只能看位置 1，位置 2 只能看位置 1～2，不能偷看右边答案。

生成时未来文字尚不存在，所以必须：

```text
预测一个 → 追加一个 → 再预测一个
```

## 4. token、token ID 和 Embedding 有什么区别？

```text
token：文本单位，本章里是一个字符，例如“模”
token ID：这个字符在词表中的编号，例如 17
Embedding：编号 17 对应的一串可训练小数
```

ID 只用于查表。`17` 不比 `16` 更有语义，也不能直接表示字符之间的相似关系。Embedding 才是模型真正用于计算的表示。

## 5. Embedding 表里的数是谁写进去的？

初始化时由 PyTorch 随机生成，训练时由下面这条链路调整：

```text
预测错误
→ Cross Entropy 得到 loss
→ loss.backward() 算出 Embedding 参数的梯度
→ optimizer.step() 修改这些数
```

程序员只设置 `vocab_size` 和 `d_model` 等尺寸，不手工编写每个字符的向量。

## 6. 为什么 Token Embedding 之外还要 Position Embedding？

Token Embedding 告诉模型“这是什么字符”，Position Embedding 告诉模型“它处在第几个位置”。

Attention 本身会比较一组向量。如果没有位置信息，交换相同字符的顺序后，模型很难区分先后关系。

本章把两者直接相加：

```text
当前位置表示 = 字符向量 + 位置向量
```

## 7. Attention 到底在做什么？

它让当前位置根据相关程度，从可见的其他位置读取信息。

可以概括成：

```text
当前位置和其他位置算匹配分数
→ softmax 得到关注比例
→ 按比例混合其他位置的 Value
```

因此 Attention 的输出不只是当前位置原来的信息，还包含从上下文汇总来的信息。

## 8. Q、K、V 是什么？

为了建立直觉，可以理解为：

```text
Query：当前位置想找什么
Key：每个位置提供什么匹配线索
Value：关注某个位置后实际取走的信息
```

但它们不是文本标签，也不是程序员定义的规则。它们都是由当前向量乘以可训练权重矩阵得到的向量。训练完成后，我们通常也不能简单断言某一维就固定代表某个人类概念。

## 9. 为什么 Attention 分数要除以 `sqrt(head_size)`？

向量维度较大时，点积的绝对值容易变大。过大的分数进入 softmax 后，概率会过早接近 0 或 1，梯度变得不稳定。

除以 `sqrt(head_size)` 是为了控制分数尺度，让训练更稳定。第一次学习先记住用途，不需要推导统计公式。

## 10. causal mask 为什么必须存在？

语言模型在预测下一个字符时，只能使用已经出现的文字。

训练时整段 input 同时进入模型，如果不遮住未来位置，预测“型”时就可能直接看到右边的“型”。这样的低 loss 来自作弊，真实生成时无法复现。

mask 把未来位置的分数设成负无穷，经过 softmax 后权重就变成 0。

## 11. Self-Attention 中的 Self 是什么意思？

Query、Key、Value 都来自同一段输入序列，所以叫 Self-Attention。

如果 Query 来自一段序列，而 Key、Value 来自另一段序列，通常称为 Cross-Attention。本章不需要 Cross-Attention。

## 12. 为什么需要多个 Attention head？

单个 head 只产生一套匹配和信息汇总结果。多个 head 在不同参数空间中分别计算，再把结果拼接起来，给模型更多种同时组织上下文的机会。

但不要把它理解成程序员提前分配：

```text
head 1 专门看主语
head 2 专门看标点
```

具体模式由训练数据和 loss 共同形成，未必能得到这么整齐的人类解释。

## 13. Attention 矩阵的形状为什么是 `[B, H, T, T]`？

```text
B：batch 中有多少段文本
H：有多少个 attention head
第一个 T：哪个位置正在查询
第二个 T：它正在关注哪个位置
```

矩阵中的一行表示一个查询位置对所有可见位置分配的权重。这一行经过 softmax 后总和为 1。

## 14. Transformer Block 只有 Attention 吗？

不是。本章的一个 Block 包含：

```text
LayerNorm
Attention
Residual
LayerNorm
Feed Forward
Residual
```

Attention 负责位置之间交换信息；Feed Forward 负责每个位置独立加工已经得到的信息；Residual 让原信息可以直接保留下来，并帮助深层网络训练。

## 15. Feed Forward 会不会再次读取其他字符？

不会。一个 Block 中，跨位置读取信息发生在 Attention。Feed Forward 对每个位置使用同一套小型 MLP，分别计算，不在位置之间传递信息。

它收到的向量已经包含 Attention 汇总的上下文，因此可以继续加工这些信息。

## 16. logits 的 `[B, T, V]` 分别是什么？

```text
B：一批有多少段文本
T：每段文本有多少个位置
V：词表中有多少种 token
```

`logits[b, t]` 是第 `b` 段文本、第 `t` 个位置对词表全部字符给出的分数。

## 17. Cross Entropy 在比较什么？

每个位置有 `V` 个 logits，同时有一个正确的下一个字符 ID。Cross Entropy 希望正确字符对应的相对分数更高。

本章把 `B × T` 个位置当成 `B × T` 道分类题，再计算平均 loss：

```text
[B, T, V] → [B×T, V]
[B, T]    → [B×T]
```

所以语言模型训练可以看成大量共享参数的多分类问题。

## 18. 为什么训练 Cross Entropy 前不先调用 softmax？

PyTorch 的 `F.cross_entropy` 接收原始 logits，并在内部组合 `log_softmax` 和负对数似然计算。这样数值更稳定，也避免重复计算。

生成时没有 target，不计算 loss，才显式使用 softmax 把最后一个位置的 logits 转成概率。

## 19. 训练和生成有什么区别？

训练：

```text
已知 input 和正确 target
→ 一次预测所有位置
→ 计算 loss
→ backward
→ 修改参数
```

生成：

```text
只有 prompt，没有正确答案
→ 预测最后一个位置之后的 token
→ 采样并追加
→ 重复
```

生成使用已经保存的参数，不调用 `backward()`，也不会修改模型。

## 20. temperature 是模型参数吗？

不是。temperature 是推理时的采样设置：

```text
next_token_logits = logits / temperature
```

低 temperature 会放大高低分之间的差异，输出更集中；高 temperature 会让概率更平坦，输出更多样。它不能补救一个没训练好的模型。

## 21. 为什么短训 80 步后生成的文字仍然像乱码？

因为“训练链路正确”和“模型能力足够”是两件事。本章默认语料只有约 1600 个字符，模型也只有约 15 万参数。

短训时 loss 虽然下降，表示模型开始学到字符频率和局部搭配，但数据量、训练步数和模型容量都不足以形成稳定语言能力。这个 tiny 模型的目标是观察原理，不是产出可用文案。

## 22. validation loss 有什么用？

train loss 衡量模型对参与参数更新的数据掌握得怎样；validation loss 衡量它对未参与更新的后段文本表现怎样。

如果：

```text
train loss 下降
validation loss 上升
```

通常说明模型正在更多地记忆训练语料，而没有同步提升对新文本的预测能力。程序保存 validation loss 最低时的 checkpoint。

## 23. 为什么词表也必须保存进 checkpoint？

模型只认识整数 ID。训练时如果 `17` 代表“模”，推理时必须维持同一映射。

如果重新生成词表导致 `17` 变成“型”，参数没有变，但所有输入和输出的含义都错位了。因此 checkpoint 同时保存字符列表。

## 24. context length 是什么？

它是模型一次最多能看到的 token 数。本章默认是 48。

训练时每个样本取连续 48 个字符；生成超过 48 个字符后，只把最近 48 个字符送回模型。更大的 context 可以保留更长历史，但 Attention 计算和显存开销也会增加。

## 25. tiny Transformer 和 GPT 的关系是什么？

两者都可以使用 causal Transformer 做 Next Token Prediction，核心数据流相似：

```text
token → embedding → transformer blocks → logits
```

主要差别在 tokenizer、网络细节、参数规模、数据规模、训练基础设施和后续对齐训练。学会本章不等于会训练 GPT，但你已经能识别大模型训练最核心的骨架。

## 学完自测参考答案

### 1. `input="模型学"` 时，target 应该怎样构造？

如果原文接下来是“习”，则：

```text
input  = 模 型 学
target = 型 学 习
```

不能只凭 `input` 猜 target，必须从原始训练文本中取右移一位的真实字符。

### 2. token ID 为什么不能直接当作字符特征？

ID 只是离散编号，数字大小和距离没有语义。Embedding 把编号映射成可以通过训练调整的向量。

### 3. 两种 Embedding 分别提供什么？

Token Embedding 提供字符身份的可学习表示；Position Embedding 提供位置的可学习表示。两者相加后，模型同时知道“是谁”和“在哪”。

### 4. Attention 主要解决什么问题？

让当前位置从可见的其他位置按相关程度读取并汇总上下文信息。

### 5. causal mask 为什么遮住右上角？

右上角代表当前位置之后的未来位置。遮住它可以防止训练时偷看答案，并让训练条件与实际生成条件一致。

### 6. `[B, T, V]` 分别是什么？

batch 数量、序列位置数量、词表大小。每个 `[b, t]` 都有 V 个下一个字符 logits。

### 7. Cross Entropy 比较什么？

比较每个位置对词表全部字符给出的 logits，与该位置真实的下一个字符 ID。

### 8. 为什么训练可并行，生成要逐个进行？

训练时完整文本和每个位置的正确答案都已知，并用 mask 限制视野；生成时下一个 token 尚不存在，必须先生成它，才能作为下一轮输入。

### 9. temperature 会修改参数吗？

不会。它只在生成时缩放 logits，改变采样概率分布。

### 10. 具体数字是谁决定的？

程序员设置维度、层数、学习率等超参数；Embedding、Q/K/V、Feed Forward 和输出层里的大量具体权重由随机初始化开始，通过训练数据、loss、反向传播和优化器学出来。
